# First Time Setup

## Requirements

Death Tracker requires **Draw Steel: CTLib** and **socketlib**, and Foundry offers to install both alongside it. CTLib holds the code the Combat Tools family of modules shares, and socketlib lets players' actions reach the Director's client.

**[Draw Steel: Target Damage](Target-Damage-Integration)** and **Draw Steel: Combat Tools** are recommended but not needed.

## Settings

Once the module is enabled in your world, open **Settings > Module Settings > Draw Steel: Death Tracker**. Everything that handles a death is on by default. The death marker, the Director's picking options and the cleanup choices start off, so those are the ones worth a look. The full list is in the [Settings Reference](Settings-Reference).

## Macros

Death Tracker's macros are in its compendium: **Power Word: Kill**, **Raise Dead** and **Revive All**. Drag the ones you want onto your hotbar. See the [Macro Reference](Macro-Reference).

## Notes

- Death handling requires the Director to be logged in to run.
- Death Tracker only handles tokens that are part of an active combat.
