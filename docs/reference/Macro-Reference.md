# Macro Reference

Death Tracker's macros live in its compendium, in the **Combat Tools** folder of the compendium sidebar.

| Macro | Description |
|---|---|
| **Power Word: Kill** | Opens the [Power Word: Kill](Power-Word-Kill) selection UI |
| **Raise Dead** | Opens the [Raise Dead](Raise-Dead) picker |
| **Revive All** | Revives every defeated token at once without opening a picker |
